# Regional Totals Summary Report

## Executive Summary
This report provides regional totals aggregated from the records dataset.

## Data Overview
- **Records Processed**: 18 records
- **Record IDs**: R002, R003, R004, R006, R007, R008, R010, R011, R012, R014, R015, R016, R018, R019, R020, R022, R023, R024
- **Regions Covered**: North, South, West

## Regional Totals (in cents)
| Region | Total |
|--------|-------|
| North  | 340,388 |
| South  | 399,267 |
| West   | 228,759 |
| **Grand Total** | **968,414** |

## Key Findings
- **South** is the highest region by total amount (399,267 cents)
- **North** is the second highest region (340,388 cents)
- **West** is the lowest region (228,759 cents)
- The South region accounts for approximately 41.2% of the total regional spending

## Methodology
All records from the input CSV file were read and aggregated by region using the amount_cents column. The totals represent the sum of all transactions for each region.
